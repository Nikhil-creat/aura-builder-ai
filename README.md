# AURA Builder AI // Matrix 3.0

A futuristic single-page concept site for an AI-driven major-project generator — built for academics, tech-job portfolios, and industry-grade builds.

**Live demo:** open `aura-builder-ai.html` directly in any browser — no build step, no dependencies.

## What it does

Type a one-line project description, optional name, tech stack, and any customisations — the in-browser generator (a rule-based domain matcher, not a live LLM call) returns:

- A recommended tech stack
- An architecture breakdown
- A live website preview mockup
- Full documentation (abstract, objectives, setup guide)
- Mode-specific additions (Academic / Job Portfolio / Industry)
- Optional injected modules: Docker, Agentic AI planning, RAG, CNN vision

Output can be copied as Markdown, downloaded as `.md`, or shared via a URL that regenerates the same blueprint.

## Tech

Pure HTML/CSS/vanilla JS — no framework, no build tools, no external API calls. Google Fonts loaded via CDN link only.
